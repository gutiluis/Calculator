# Swift Calculator

This calculator will handle addition, subtraction, multiplication, and division.


---

## How it works:

```
swift calculator.swift
```

---

### Features:
- Prompts the user for two numbers and an operator.
- Checks if the input is valid.
- Performs the calculation using a switch.
- Prints the result.
